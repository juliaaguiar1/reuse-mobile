# ReUse — Sprint 1 | Mobile

Aplicativo mobile desenvolvido em React Native com Expo para a Sprint 1 da FIAP.

## Contexto
O ReUse é uma plataforma voltada à economia sustentável, reutilização de produtos e consumo consciente.

## Proposta de valor
**Dê uma nova vida ao que você já tem.**

## Problema
Produtos ainda úteis são descartados diariamente, aumentando a geração de resíduos e incentivando compras desnecessárias.

## Decisões de UI
A interface utiliza verde escuro, verde claro e off-white, com cards arredondados, hierarquia tipográfica, espaçamentos consistentes e Flexbox para organização responsiva.

## Componentes reutilizáveis
- FeatureCard
- ImpactPill
- SectionLabel
- NativeActionButton

## Componentes React Native utilizados
- View
- Text
- Button
- Pressable
- Modal
- ScrollView
- SafeAreaView

## Interações
- Conhecer o ReUse
- Menos descarte
- Mais reutilização
- Reutilizar
- Conectar
- Conscientizar
- Ícone do ciclo ReUse

Todas as interações são locais e não utilizam backend, APIs, banco de dados ou autenticação.
